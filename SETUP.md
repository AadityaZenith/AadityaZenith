# Fix / install your GitHub profile README

## Important
Upload `README.md` and the complete `assets/` folder together. The banner is stored in `assets/cyber-hero.svg` and the divider in `assets/neon-divider.svg`.

## Steps
1. Open your actual GitHub username's profile repository.
2. Open `README.md` and click the pencil (Edit) icon.
3. Replace the entire file with the corrected `README.md` from this package.
4. Commit the changes.
5. Upload the `assets/` folder to the same repository root if it is not already present.
6. Replace the LinkedIn placeholder with your real profile URL.

GitHub profile READMEs use GitHub-flavoured Markdown. Pandoc-specific markers such as `{=html}` and `::: {align="center"}` are not GitHub README syntax and can show up as literal text. GitHub does not execute JavaScript in README files; visual effects must be images/SVGs or externally hosted image cards.

For the profile README to appear at the top of a profile, the public repository name must exactly match the user's GitHub username.
